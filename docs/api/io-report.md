# `mambo_power.io.report`

The typed conversion reports: `ImportReport` (returned by every importer's
`load_with_report`) and `ExportReport` (returned by every exporter), plus the `LIMITATIONS`
registry of the codes each format module can emit. An empty report means the conversion was
lossless. See [File formats › Warnings](../manual/formats.md#warnings-repairs).

::: mambo_power.io.report
