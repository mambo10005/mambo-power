# `mambo_power.io.report`

The typed conversion reports: `ImportReport` (returned by every importer's
`load_with_report`) and `ExportReport` (returned by every exporter). An empty report means the
conversion was lossless. See [File formats › Warnings](../manual/formats.md#warnings-repairs);
the registry of codes per module is [`io.limitations`](io-limitations.md).

::: mambo_power.io.report
